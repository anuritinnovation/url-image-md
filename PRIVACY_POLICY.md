# Privacy Policy

**Effective Date:** February 12, 2026

The **Dynamic URL Image Visual** ("the Visual") for Power BI is committed to protecting your privacy.

## 📁 Data Collection and Usage
The Visual does not collect, store, or transmit any personal identification information (PII) or sensitive data from your Power BI reports.

### Local Processing
- **Rendering:** All data processing for image rendering happens locally within your Power BI environment (browser or Desktop).
- **URLs:** The Visual fetches images directly from the URLs provided in your dataset.

## 🌐 External Communication
The Visual only communicates with external servers to:
1.  **Fetch Images:** Requests are made to the URLs provided by the user to display the image.
2.  **Navigation:** When a user clicks an image with a "Redirect URL" mapped, the Visual uses the Power BI `launchUrl` API to open the browser. 

No data is sent to the developer or any third-party analytics services.

## 🔒 Security
The Visual adheres to Power BI security best practices and requires all visual assets and redirection targets to use secure `https://` protocols.

By using the Dynamic URL Image Visual, you consent to our privacy policy.
